# Wails-биндинги

## Принцип работы

Wails автоматически генерирует JavaScript-обёртки для каждого публичного метода Go-хендлеров. Генерация происходит при сборке проекта командой `wails build` или `wails dev`.

Файлы биндингов расположены в `frontend/wailsjs/go/<пакет>/`:
- `Handler.js` — JavaScript-функции, вызывающие Go через `window['go']`
- `Handler.d.ts` — TypeScript-декларации с типами аргументов и возвращаемых значений

Заголовок каждого файла содержит предупреждение: `// This file is automatically generated. DO NOT EDIT`

Каждая JS-функция является тонкой обёрткой:

```js
// frontend/wailsjs/go/auth/Handler.js
export function Login(arg1) {
    return window['go']['auth']['Handler']['Login'](arg1);
}
```

Все функции возвращают `Promise`. При успехе промис разрешается с данными (или `void`). При ошибке отклоняется со строкой ошибки — её принято передавать в `showError(err)`.

Биндинги доступны в любом JS-файле через прямой импорт:

```js
import { Login } from '../../../wailsjs/go/auth/Handler'
```

## Пакеты и функции

### auth

Файлы: `wailsjs/go/auth/Handler.js`, `Handler.d.ts`

| Функция | Сигнатура TypeScript | Описание |
|---|---|---|
| `Authenticate` | `(): Promise<void>` | Проверяет наличие активной сессии. Вызывается в `App.js` при монтировании |
| `Login` | `(arg1: LoginDTO): Promise<void>` | Вход по логину (email или username) и паролю |
| `Register` | `(arg1: RegisterDTO): Promise<void>` | Регистрация нового пользователя |
| `Logout` | `(): Promise<void>` | Завершение сессии |
| `SendVerifyEmail` | `(arg1: string): Promise<void>` | Отправка письма подтверждения email |
| `SendForgetPassword` | `(arg1: string): Promise<void>` | Отправка письма со ссылкой сброса пароля |
| `ForgetPassword` | `(arg1: string, arg2: ForgetPasswordDTO): Promise<void>` | Сброс пароля по токену из письма |
| `ChangePassword` | `(arg1: ChangePasswordDTO): Promise<void>` | Смена пароля: требует старый и новый пароль |
| `StartListening` | `(): Promise<void>` | Служебный метод хендлера |
| `StopListening` | `(): Promise<void>` | Служебный метод хендлера |
| `SetContext` | `(arg1: context.Context): Promise<void>` | Служебный метод хендлера |

Используется в: `App.js`, `LoginView.js`, `ForgetPasswordModal.js`, `ProfileModal.js`

## Runtime Events

Файлы: `wailsjs/runtime/runtime.js`, `runtime.d.ts`

Wails Runtime доступен в браузерном контексте через `window.runtime`. Предоставляет событийную шину для двусторонней коммуникации Go <-> JS.

В проекте используются следующие функции:

```ts
// Подписка на событие от Go-бэкенда
EventsOn(eventName: string, callback: (...data: any) => void): () => void

// Отписка от события
EventsOff(eventName: string, ...additionalEventNames: string[]): void

// Отправка события в Go-бэкенд (в проекте не используется напрямую)
EventsEmit(eventName: string, ...data: any): void
```

Пример использования из `ChatView.js`:

```js
// onMounted
window.runtime.EventsOn(WAILS_EVENT.NEW_MESSAGE, handleNewMessage)
window.runtime.EventsOn(WAILS_EVENT.CHATS_UPDATED, handleChatsUpdated)

// onUnmounted
window.runtime.EventsOff(WAILS_EVENT.NEW_MESSAGE)
window.runtime.EventsOff(WAILS_EVENT.CHATS_UPDATED)
```

## TypeScript-модели

Файл: `wailsjs/go/models.ts`

Содержит TypeScript-классы, сгенерированные из Go-структур. Каждый класс имеет статический метод `createFrom(source)` и конструктор, принимающий объект или JSON-строку.

### User
```ts
class User {
    id: number
    username: string
    email: string
    emailConfirmed: boolean
    password: string
    createdAt: any   // Go: time.Time
    updatedAt: any
}
```

### Message
```ts
class Message {
    id: number
    chatId: number
    sender: User
    text: string
    createdAt: any
    updatedAt: any
    isRead: boolean
}
```

### Chat
```ts
class Chat {
    id: number
    title?: string
    description?: string
    type: string        // 'private' | 'group'
    createdAt: any
    updatedAt: any
    unreadCount: number
    members?: User[]
    messages?: Message[]
}
```

### DTO (Data Transfer Objects)

| Класс | Поля | Используется в |
|---|---|---|
| `LoginDTO` | `login: string`, `password: string` | `auth.Login` |
| `RegisterDTO` | `username: string`, `email: string`, `password: string` | `auth.Register` |
| `ForgetPasswordDTO` | `newPassword: string` | `auth.ForgetPassword` |
| `ChangePasswordDTO` | `oldPassword: string`, `newPassword: string` | `auth.ChangePassword` |
| `CreateChatDTO` | `type: string`, `memberIDs?: number[]`, `title?: string`, `description?: string` | `chats.CreateChat` |
| `UpdateUserDTO` | `username?: string` | `users.UpdateUser` |
| `UsersFilters` | `username?: string` | `users.SearchUsers` |
| `Pagination` | `limit?: number`, `offset?: number` | `chats.GetUserChats`, `messages.GetChatMessages` |
