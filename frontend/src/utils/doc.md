# frontend/src/utils

## Назначение

Утилитарные функции фронтенда.

## debounce.js

Экспортирует функцию `debounce(fn, delayMs)`.

Классическая реализация дебаунса: сбрасывает предыдущий таймер при каждом вызове, выполняет `fn` после `delayMs` миллисекунд тишины.

### Использование

- `CreateChatModal` — дебаунс поиска пользователей при создании чата
- `SearchUsersModal` — дебаунс поиска пользователей

Задержка передаётся из константы `SEARCH_DEBOUNCE_MS` (500 мс).
