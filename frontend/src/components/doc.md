# frontend/src/components

## Назначение

Vue 3 компоненты приложения. Каждый компонент — папка с тремя файлами: `.vue` (шаблон), `.js` (логика, Options API с `setup()`), `.css` (стили, BEM).

## Компоненты

| Компонент | Описание |
|-----------|----------|
| `ChatView` | Главный экран: сайдбар со списком чатов, область переписки, тулбар. Real-time обновление через Wails Events |
| `LoginView` | Экран входа и регистрации с двумя вкладками |
| `AlertModal` | Модальное окно ошибок и информационных сообщений |
| `NotificationToast` | Эфемерное всплывающее уведомление о новом сообщении |
| `CreateChatModal` | Создание приватного или группового чата с поиском пользователей |
| `GroupChatModal` | Информация о групповом чате и список участников |
| `SearchUsersModal` | Поиск пользователей по имени с дебаунсом |
| `ForgetPasswordModal` | Сброс пароля по коду из письма |
| `ProfileModal` | Профиль текущего пользователя: редактирование, смена пароля, тема |
| `EmojiPicker` | Панель выбора эмодзи (4 категории) |
