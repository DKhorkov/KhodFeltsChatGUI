# Компонент SearchUsersModal

## Назначение

Модальное окно поиска пользователей по имени с дебаунсом. При клике на пользователя отображает его профиль внутри модалки.

## Emits

| Событие | Когда |
|---------|-------|
| `close` | Клик на оверлей или кнопку закрытия |

## Inject

- `showError`

## Ключевое состояние (refs)

| Ref | Описание |
|-----|----------|
| `searchQuery` | Строка поиска |
| `searchResults` | Результаты поиска |
| `hasSearched` | Был ли хотя бы один поиск (для «не найдено») |
| `selectedUser` | Выбранный пользователь для просмотра профиля |

## Ключевые функции

| Функция | Описание |
|---------|----------|
| `handleSearchInput` | Дебаунс-обёртка (`SEARCH_DEBOUNCE_MS`) |
| `formatDate(dateStr)` | Форматирует дату в локаль `ru-RU` |

## Wails-биндинги

`users/Handler`: `SearchUsers`
