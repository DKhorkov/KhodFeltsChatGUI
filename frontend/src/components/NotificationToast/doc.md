# Компонент NotificationToast

## Назначение

Эфемерное всплывающее уведомление о новом сообщении. Отображается в стопке уведомлений, управляемой `App.js`.

## Props

| Prop | Тип | Обязательный | Описание |
|------|-----|--------------|----------|
| `message` | `String` | да | Текст уведомления |
| `sender` | `String` | нет (`''`) | Имя отправителя |

## Emits

| Событие | Когда |
|---------|-------|
| `click` | Клик на тело уведомления |
| `close` | Клик на кнопку закрытия (×) |

## Особенности

Чистый презентационный компонент. Время жизни (`NOTIFICATION_DURATION_MS`) контролируется родителем (`App.js`).
