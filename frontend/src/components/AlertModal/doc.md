# Компонент AlertModal

## Назначение

Модальное окно для отображения ошибок и информационных сообщений. Блокирующий диалог с кнопкой «OK».

## Props

| Prop | Тип | Обязательный | Описание |
|------|-----|--------------|----------|
| `message` | `String` | да | Текст сообщения |
| `type` | `String` | нет (`'info'`) | `'error'` или `'info'` |

## Emits

| Событие | Когда |
|---------|-------|
| `close` | Клик на оверлей, Escape, нажатие OK |

## Особенности

Чистый презентационный компонент без inject, refs и функций. Использует директиву `v-focus` для захвата фокуса. Стиль заголовка и иконка зависят от `type`.
