# Компонент EmojiPicker

## Назначение

Панель выбора эмодзи с переключением по категориям. Отображается поверх поля ввода сообщения в `ChatView`.

## Emits

| Событие | Когда | Данные |
|---------|-------|--------|
| `select` | Клик на эмодзи | строка эмодзи |

## Категории

Определены как модульная константа `CATEGORIES`:

| Ключ | Метка | Количество |
|------|-------|------------|
| `smileys` | Смайлы | 56 |
| `gestures` | Жесты | 32 |
| `hearts` | Сердца | 24 |
| `objects` | Объекты | 32 |

## Ключевое состояние

| Ref / Computed | Описание |
|----------------|----------|
| `activeCategory` | Имя активной категории (по умолчанию `smileys`) |
| `activeEmojis` | Массив эмодзи выбранной категории (computed) |
