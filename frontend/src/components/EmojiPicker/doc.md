# Компонент EmojiPicker

## Назначение

Панель выбора эмодзи. Все эмодзи отображаются в одной прокручиваемой сетке без разделения по категориям. Показывается поверх поля ввода сообщения в `ChatView` при наведении курсора на кнопку эмодзи.

## Emits

| Событие | Когда | Данные |
|---------|-------|--------|
| `select` | Клик на эмодзи | строка эмодзи |

## Данные

Все эмодзи хранятся в модульной константе `ALL_EMOJIS` — плоский массив из 144 эмодзи (смайлы, жесты, сердца, объекты).

## Поведение показа/скрытия

Управляется родительским компонентом `ChatView`:
- Открытие: `mouseenter` на враппере кнопки эмодзи
- Закрытие: `mouseleave` с задержкой 500мс — если курсор вернётся на враппер до истечения таймера, закрытие отменяется
