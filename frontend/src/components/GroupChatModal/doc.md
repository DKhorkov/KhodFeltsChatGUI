# Компонент GroupChatModal

## Назначение

Модальное окно с информацией о групповом чате: аватар, название, описание и список участников.

## Props

| Prop | Тип | Обязательный | Описание |
|------|-----|--------------|----------|
| `chat` | `Object` | да | Объект чата |
| `currentUser` | `Object` | да | Текущий пользователь (для пометки «вы») |

## Emits

| Событие | Когда | Данные |
|---------|-------|--------|
| `close` | Клик на оверлей или кнопку закрытия | — |
| `open-member-profile` | Клик на участника | объект `User` |

## Вычисляемые свойства

| Computed | Описание |
|----------|----------|
| `chatTitle` | `chat.title` или `Чат #id` |
| `chatInitial` | Первая буква названия в верхнем регистре |
| `membersCount` | Количество участников |
