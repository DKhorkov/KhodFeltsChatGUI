# Компонент ForgetPasswordModal

## Назначение

Модальное окно сброса пароля. Пользователь вводит код из письма, новый пароль и подтверждение.

## Props

| Prop | Тип | Обязательный | Описание |
|------|-----|--------------|----------|
| `message` | `String` | да | Информационное сообщение (адрес, на который отправлено письмо) |

## Emits

| Событие | Когда |
|---------|-------|
| `close` | Успешный сброс пароля или нажатие «Назад» |

## Inject

- `showError`, `showInfo`

## Ключевое состояние (refs)

| Ref | Описание |
|-----|----------|
| `token` | Код из письма |
| `newPassword` | Новый пароль |
| `confirmPassword` | Подтверждение пароля |

## Ключевые функции

| Функция | Описание |
|---------|----------|
| `resetPassword()` | Валидирует поля, проверяет совпадение паролей, вызывает `ForgetPassword(token, {newPassword})`, закрывает модалку |

## Wails-биндинги

`auth/Handler`: `ForgetPassword`
