# Пакет internal/v1

## Назначение

Устаревшая (legacy) версия GUI на базе Fyne. Заменена на v2 (Wails + Vue 3).

## Структура

- `widgets/` — кастомные Fyne-виджеты (entries с валидацией).
- `windows/` — оконные формы: `auth`, `chat`, `create_chat`, `forget_password`, `information`, `notification`, `search_users`.

## Статус

Код сохранён для справки. Активная разработка ведётся в `internal/v2/`.
