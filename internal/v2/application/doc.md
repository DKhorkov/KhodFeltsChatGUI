# Пакет `internal/v2/application`

## Назначение

Точка сборки Wails-приложения. Управляет жизненным циклом: инициализация хендлеров при запуске, остановка при закрытии, биндинг хендлеров для доступа из фронтенда.

## Типы

| Тип | Описание |
|-----|----------|
| `App` | Основная структура приложения Wails. Хранит `UseCases`, логгер, маппер ошибок и список хендлеров |

## Конструктор

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| `New` | `New(useCases, logger, errorsMapper, handlers) *App` | Создает экземпляр приложения со всеми зависимостями |

## Методы

| Метод | Сигнатура | Описание |
|-------|-----------|----------|
| `Startup` | `(ctx context.Context)` | Вызывается Wails при запуске. Передает контекст всем хендлерам через `SetContext` |
| `Shutdown` | `(_ context.Context)` | Вызывается Wails при закрытии. Останавливает прослушивание во всех хендлерах через `StopListening` |
| `BindHandlers` | `() []any` | Возвращает срез хендлеров как `[]any` для регистрации в Wails runtime (биндинг Go-функций для вызова из JS) |

## Зависимости

- `github.com/DKhorkov/libs/logging` -- логирование
